# Parte B — Elemento Generativo

Para este trabalho, parti do código inicial e explorei a possibilidade de introduzir movimento na composição através da alteração de um dos seus elementos. Acabei por optar pela mudança de cor de um dos retângulos, mantendo os restantes elementos iguais. Para o fazer, utilizei uma variável que permite alterar gradualmente a cor e defini um ciclo para que, ao chegar ao limite estabelecido, esta voltasse ao valor inicial. Desta forma, a cor muda continuamente enquanto o programa está em execução. Escolhi esta solução por ser uma forma simples de explorar as possibilidades do p5.js e perceber como pequenas alterações no código podem transformar uma composição estática numa composição dinâmica, sem alterar a sua estrutura original.
